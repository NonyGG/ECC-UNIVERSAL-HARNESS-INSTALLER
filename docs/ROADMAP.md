# Roadmap

- **1.0.0** — gate: core stable; OpenCode adapter certified; at least one
  second harness with real operational proof; update/rollback proven; security
  audited; cross-platform CI green (Windows + Linux).
- **Tier 2 adapters** — Claude Code, Codex CLI, Cursor, Gemini CLI: analysis →
  fixture install → real proof → promotion to SUPPORTED.
- **Tier 3** — Cline, Windsurf, Aider, Qodo, and others listed: adapter
  skeleton → analysis → fixture, without claiming support.
- **macOS/WSL CI** when environment becomes available.
- **Large-scale benchmarks** (10k+ decisions, concurrent installs).
- **Publishing** only as an explicit owner action after certification.

Evolution is driven by evidence (operational proof per adapter) and the
publication gates (G1–G15).
